## 목표

에이전트 파이프라인의 **이미지 캡션(참조 이미지 설명)** 용 비전-언어(VL) 모델을
GB10(aarch64 · Blackwell · 통합메모리 119GB)에서 서빙 가능한지 검증하고 확정한다.
PRD 지향은 "비중국 / NVIDIA 모델 스택".

## 테스트 방법 (재현)

### A. ollama 경로 (gemma / llama3.2-vision)

```bash
# 이미지를 base64로 파일에 담아 API 호출 (인라인은 ARG_MAX 초과로 실패)
python3 - assets/howtouse1.png /tmp/vis.json <<'PY'
import sys, json, base64
img, out = sys.argv[1], sys.argv[2]
b64 = base64.b64encode(open(img,'rb').read()).decode()
json.dump({"model":"gemma4:latest","prompt":"Describe this image in one sentence.",
           "images":[b64],"stream":False}, open(out,'w'))
PY
curl -s -m200 -o /tmp/resp.json -w '%{http_code}\n' \
  http://localhost:11434/api/generate -d @/tmp/vis.json
python3 -c "import json;d=json.load(open('/tmp/resp.json'));print(d.get('response') or d.get('error'))"
```

- gemma4:latest → HTTP 200, "composite demonstrating AI creative tools ... image/video
  modification interface" (상세)
- gemma3:4b → HTTP 200, "portrait of ... East Asian female ... yellow mascot"
- llama3.2-vision:11b → **HTTP 500** `unknown model architecture: 'mllama'`

## 실패 이유 (NVIDIA Nemotron-Nano-VL-8B)

VL 모델 = **비전 인코더(눈)** + **LLM(입)** 결합. 두 겹으로 막힘.

1. **ollama 불가 — 비전 인코더 규격.**
   ollama 밑단 llama.cpp는 CLIP/SigLIP 계열 인코더만 안다. Nemotron-Nano-VL의
   눈은 NVIDIA 자체 **C-RADIO** → llama.cpp에 로더 코드 없음. GGUF 변환해도 못 굴림.
   (llama3.2-vision의 `mllama`도 같은 부류로 이 빌드에서 미지원.)

2. **transformers 네이티브도 버전 비호환.**
   ollama 우회해 파이썬 직접 서빙 시도. 의존성 timm·open_clip 설치 + 17GB 다운
   후에도 로드 실패 연쇄:
   - 기본 `flash_attention_2` 미지원 → `attn_implementation="eager"`로 회피
   - 다음: `AttributeError: 'Llama_Nemotron_Nano_VL' object has no attribute
     'all_tied_weights_keys'` — 모델 커스텀코드가 **옛 transformers(≈4.4x)** 기준.
     huyuan-env는 Blackwell(GB10) 지원 때문에 **transformers 5.12 필수**라 충돌.

3. **transformers 다운그레이드 불가.**
   4.x로 내리면 5.12를 쓰는 영상 생성 서버(:8500 hunyuan_server)가 깨진다.
   캡션 하나 위해 상주 서버를 희생할 수 없음 → **최종 배제**, 17GB 캐시 삭제.

**핵심**: NVIDIA 소형 VLM = (특수 비전 인코더 + 옛 transformers 기준 커스텀코드)
조합이라 이 스택에서 마찰 과다. gemma는 표준 인코더 + ollama 자체 엔진이라
transformers 버전 싸움과 무관 → 명령 한 줄로 동작.

## 남은 흔적

- huyuan-env에 `timm`, `open_clip_torch` 설치됨(무해, 다른 모델 재사용 가능).
- Nemotron-VL 17GB HF 캐시는 삭제됨.

## 재평가 트리거

- ollama(llama.cpp)가 C-RADIO / mllama 인코더를 지원하게 되면 재시도.
- 별도 venv(옛 transformers 핀)를 감수할 만큼 NVIDIA VL 품질이 필요해지면 재검토.
