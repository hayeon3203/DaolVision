# PRD — 오픈셸 자립형 생성 스튜디오 (LocalAI UI + 비중국/NVIDIA 모델 스택)

작성일: 2026-07-28
상태: 초안
마감: 2026-08-04 (착수일 기준 7일)
근거: `/grill-me` 인터뷰 세션 (2026-07-28, Q1~Q33)

---

## 목적

기존 anim 영상 에이전트(:8700 LangGraph, T2I→I2V)를 **오픈셸(자립·오프라인·오픈소스 전용)
환경에서 동작하는 생성 스튜디오**로 고도화한다. UI는 `mudler/LocalAI`를 포크해 외형만 사용하고,
추론은 전부 로컬 백엔드가 담당한다. 핵심 차별점은 **모든 모델이 비중국 또는 NVIDIA 계열의
오픈소스**라는 점이며, 국적과 오프라인 여부, 메모리 사용량을 대시보드로 시각화해 증명한다.

발표는 **라이브 시연과 녹화 백업을 함께** 준비한다. 라이브 시연을 목표로 하되, OOM이나 타임아웃에 대비해 시나리오마다 사전 녹화본을 준비한다.

## 대상 사용자

- 발표/심사 대상 (데모 관객). 배점: **UI 40% · 에이전트 동작 50% · (기타 10%)**
- 프로젝트 소유자 본인 (운영·시연)

## Goals

- 오픈셸 안에서 **텍스트 스토리 → 캐릭터 일관 영상 + 나레이션(TTS)** 전 과정이 로컬에서 동작한다 (S1)
- **내 얼굴 → 그림체 변환**(애니/초상화/프로필/우주비행사) I2I (S2)
- **전 모델 비중국/NVIDIA**임을 대시보드로 시각 증명 (국적·오프라인·GB10 메모리)
- LocalAI 룩앤필의 UI에서 카테고리 선택 → 스타일 선택 → 생성, Agent는 상단 **노드 스텝퍼**로 진행 표시

## Non-goals (각본을 기준으로 범위를 고정한다)

- **위시리스트에 있는 모델을 전부 통합하지 않는다**: T2I 8종과 TTS 6종 등은 후보였을 뿐이므로, 실제 각본에 사용하는 것만 구현한다
- LocalAI의 **추론 백엔드는 사용하지 않는다**(프론트엔드 외형만 포크하고, 실제 연결은 자체 백엔드로 한다)
- neural-doodle(그림판→미술관)은 2016년의 구식 기술이므로 **폐기한다**
- Ideogram(클로즈드 API), Flux.2/SD1.5/2.0/SD3.5/Anima 등 미사용 후보 — **UI 노출도 안 함** (S1/S2 각본에 없음)
- TTS 감정 톤 conditioning, 오디오북/더빙, 정밀 립싱크
- S3를 독립 시나리오로 만들지 않으며, 스타일은 **앞단의 공통 셀렉터**에 통합한다
- 씬간 색조/조명 100% 연속성 보장 (완화만)
- 실시간 세부 진행바(앵커 3/4장)는 만들지 않으며, 스텝퍼는 phase 단위로만 표시한다
- 다중 사용자/권한

## 시나리오 (각본을 구현의 기준으로 삼는다)

실질적인 시나리오는 **2개(S1 영상, S2 얼굴변환)**이다. 스타일은 두 시나리오 모두의 앞단에 놓이는 공통 옵션이며, S1부터 S2 순서로 단계적으로 구현한다.

```
UI 플로우: 카테고리 선택 → 스타일 프리셋 선택 → 입력 → 생성
스타일 프리셋(공통 셀렉터, 프롬프트 프리픽스 주입):
  시네마틱 · 애니메이션 · 픽셀아트 · 사이버펑크
```

### S1 — 우주비행사의 여정 (메인, 에이전트 50%)

- **각본**: 발사 → 우주유영 → 외계행성 → 귀환. **4씬.** 투명 바이저로 얼굴 노출(Face-ID 일관성 시연용).
- **캐릭터 소스**: S2에서 만든 우주비행사 캐릭터를 S1 Face-ID 참조로 전달 (S2→S1 연결).
- **파이프**: 씬분할 → (씬별)T2I 앵커 → I2V 클립(캐릭터+화풍 일관) → 자막편집 게이트 → **Chatterbox CC0 한국어 화자** 나레이션 mux → 최종 mp4.
- **승인 3게이트**(interrupt): 씬분할 / 클립 / 자막편집. 챗 멀티턴(기존 `openwebui_anim_function.py` 마커 패턴 이식).
- **영상 TTS 고정**: S1은 **Chatterbox V3 + 고정 CC0 한국어 화자**를 사용한다. 사용자 음성 파일 유무에 따라 나레이션 화자가 바뀌지 않는다.

### S2 — 내 얼굴 → 그림체 변환 (I2I)

- **입력**: 사용자 얼굴사진 1장.
- **출력 4종**(Flux.1 Kontext, 프롬프트만 교체): **애니메이션 · 유화 초상화 · 프로필 사진 · 우주비행사**(S1 연결용).

### 독립 TTS — 내 목소리

- **진입점**: LocalAI 사이드바의 TTS 카테고리. S1 Agent 파이프와 분리한다.
- **입력**: 한국어 텍스트 + 사용자 소유/사용 허가를 받은 참조 `reference.wav`.
- **엔진**: **Chatterbox Multilingual V3**의 한국어(`ko`) zero-shot voice cloning.
- **출력**: 24kHz mono WAV. 참조 원본과 결과는 로컬 파일시스템에만 보관한다.
- **보관**: `private/tts/voices/<voice_id>/reference.wav`와 대응 대본 `reference.txt`; `private/`는 Git 제외.
- **라우팅**: `POST /tts/clone`. 다른 화자로 자동 폴백하지 않으며, 참조 음성이 없으면 명시적 입력 오류를 반환한다.

## 아키텍처

**단일 게이트웨이 :8700**을 사용한다 (Q24-a). LocalAI 프론트는 :8700만 호출하고, :8700이 라우팅과 OOM 오케스트레이션, 대시보드 집계를 총괄한다.

```
브라우저 (LocalAI 포크 프론트: Go템플릿+Alpine)
   │  HTTP
   ▼
:8700 FastAPI 게이트웨이  ── 라우팅 · OOM 배치 오케스트레이션 · 대시보드 메타 집계
   ├─> :11434  Ollama (Nemotron-4B 씬분할 / Nemotron-VL-8B 캡션)
   ├─> :8501   T2I (Flux.1-schnell)
   ├─> :8188   ComfyUI (I2V: LTX distilled+Face-ID / Cosmos 벤치, I2I: Flux Kontext)
   ├─> TTS 나레이션 (Chatterbox V3 + CC0 한국어 화자, POST /tts/narration)
   └─> TTS 사용자 음성 (Chatterbox V3, POST /tts/clone)
```

- LocalAI 사이드바 기존 카테고리 재활용(Images/Video/TTS/Agents). 신규 = **Agent 상단 노드 스텝퍼 1개** + 스타일 셀렉터 + 자립 대시보드 탭.
- 프론트엔드의 API 호출을 :8700으로 변경한다. LocalAI 추론 백엔드는 사용하지 않는다.

## OOM 전략 (최우선 제약)

- GB10 = 119GB 통합메모리. **단순 합산 예측 불가**(과거 45GB fragmentation OOM 이력) → **Day1 실측이 게이트**.
- **주력: 전 모델 상주(언로드 회피).** 총합 ~55-60GB 추정 → 동시상주 가능하면 **로드부하 최초 1회뿐(이후 0).**
- **폴백: 배치 온디맨드 언로드**를 사용한다(상주에 실패한 경우). 무거운 모델의 로드는 배치로 최소화한다(파이프라인당 1회만 로드해 전 씬을 처리하고, 씬마다 로드와 언로드를 반복하지 않는다).
- **distilled 채택**으로 총합 축소 → 상주 확률 최대화.
- 상주 여부와 언로드 로직은 :8700 게이트웨이가 총괄한다.

## UI

- 사이드바 카테고리(LocalAI 기존 재활용): **[Agent 스토리영상(T2I→I2V)] [I2V 단발샷] [I2I 얼굴변환] [TTS]**
  (2026-07-31 개편: 독립 T2I 카테고리 폐지 — T2I는 Agent 내부 단계로만 존재.
  I2V 단발샷(LTX-13B-distilled, Face-ID 없이 사진+텍스트→영상, 3.8 스파이크)을
  신규 카테고리로 추가. 추후 T2V 카테고리(Cosmos, 단발샷) 검토 예정 — 아직
  미착수, 별도 후속 태스크)
- 대화 히스토리: LocalAI 기존 재활용(agent 포함 전부 챗 히스토리)
- **Agent 카테고리**: LocalAI 챗 UI 그대로 + **상단 노드 스텝퍼**(경량, Alpine) — 씬분할→앵커→I2V→TTS→합성 phase 하이라이트. 승인 3게이트는 챗 메시지로.
- **스타일 셀렉터**: 카테고리 진입 후 프리셋 칩(프롬프트 프리픽스 주입)
- OpenMontage를 전부 구현하지는 않으며(씬카드 그리드와 Decision Log는 제외한다) 스텝퍼만 구현한다

### 자립 대시보드 (오픈셸을 시각적으로 증명하며, 배점상 핵심이다)

- **상단 배지**: 🔒 OFFLINE(localhost-only) · 📖 OPEN-SOURCE · 🌐 비중국 ✓
- **패널 A — 실행 트레이스**: 파이프 각 스텝의 타겟 URL(전부 127.0.0.1) + 모델 + 국적깃발 + 라이센스 + VRAM. **External calls: 0 실측**(`ss` 아웃바운드 폴링, Q23-b)
- **패널 B — GB10 메모리 게이지**: 119GB 중 사용량과 여유량을 실측하며, 모델을 로드하거나 언로드할 때 값이 실시간으로 변동한다
- 데이터소스: :8700 `/dashboard/status` 폴링
